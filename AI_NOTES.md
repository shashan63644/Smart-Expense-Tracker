How I Used AI

I used Chatgppt as a learning and development assistant while building this project. It helped me understand the assignment requirements, plan the project structure, and solve issues whenever I got stuck

What AI Helped Me With

Understanding how to organize the project into routes, controllers, services, and middleware.
Writing the basic REST API endpoints.
Learning how to store data in a local JSON file.
Creating automated tests using Jest and Supertest.
Preparing the README file




What I Did Myself

I created the project in VS Code, installed the required packages, connected all the files, and implemented the API. I tested every endpoint using Postman and fixed errors whenever something didn't work. I also ran the Jest tests, resolved the issues, and made sure all the tests passed successfully



What I Changed

I didn't copy the AI generated code directly.
I understood the suggestions, made changes where needed, fixed bugs, improved the validation, and tested everything before keeping it in the final project



Suggestions I Didn't Use

AI suggested using a database like MongoDB and changing the project to use ES Modules. I decided not to use those ideas because the assignment only required local storage, and keeping the project simple with a JSON file and CommonJS was enough for the requirements



Final Note

AI helped me learn faster and solve problems, but I reviewed, tested, and verified the final implementation myself to make sure the project worked correctly.
